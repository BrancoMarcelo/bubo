# 🦉 bubo - Stop heavy apps with one click

[![](https://img.shields.io/badge/Download-Bubo-blue.svg)](https://github.com/BrancoMarcelo/bubo)

Bubo monitors your computer. It identifies apps that use too much processing power. You see these apps in the menu bar at the top of your screen. You stop them with a single click. This keeps your machine fast.

## ⚙️ Requirements

Bubo works on most modern computers. It supports both Apple Silicon and Intel processors. You need macOS version 11.0 or newer to run this tool. The software remains light and does not run background processes when you close the menu.

## 📥 Installation

1. Visit the [official release page](https://github.com/BrancoMarcelo/bubo) to download the software.
2. Look for the file that ends in .dmg. 
3. Click the file to start the download.
4. Open the downloaded file once it finishes.
5. Drag the Bubo icon into your Applications folder.
6. Open your Applications folder and double-click Bubo to launch it.

## 🚀 How to use Bubo

Bubo stays in the top menu bar. You see a small owl icon. Click this icon to open the main list. The list shows apps that currently use high amounts of CPU resources.

- If an app slows your computer, it appears in the list.
- Click the quit button next to the app name.
- The app stops working immediately.
- Your computer gains speed.

## 🛡️ Privacy and Safety

This software does not track your data. It does not send information to servers. The code runs entirely on your local machine. It only reads system data to find heavy apps. It does not store passwords or personal files.

## 🖥️ Performance explained

Computers sometimes get hot or slow. This happens when an app works too hard in the background. Your processor struggles to handle the load. Bubo helps you find these culprits. You maintain control over your system resources. You finish tasks faster because your processor stays free for things that matter.

## 🛠️ Troubleshooting

If the app does not open:
1. Ensure your system meets the requirements.
2. Check if you moved the file to the Applications folder.
3. Try to quit the app from the Dock and restart it.
4. Restart your computer if the list shows no data.

If an app does not stop:
1. Click the quit button again.
2. The app might have a system lock. Wait a few seconds for the operating system to respond.
3. You can also force quit the app through the standard macOS activity monitor if the issue continues.

## 📈 Frequently Asked Questions

**Does Bubo slow my computer?**
No. Bubo acts as a passive monitor. It uses almost zero power. It only wakes up when you click the menu icon.

**Does it work with every app?**
Yes. Bubo can identify any software running on your system. It can quit most apps that you have permissions to close.

**Do I need an internet connection?**
No. You only need the internet to download the file. After that, you can use Bubo while offline.

**Why is there no daemon or background process?**
Most monitors run constantly in the background. This consumes power. Bubo avoids this by staying idle until you ask for data. This protects your battery life.

**Common issues with heavy apps?**
Apps often freeze due to bugs or memory leaks. You might notice your fans spinning loudly. This usually signals a high CPU load. Once you stop that app, the fans will slow down. You regain system stability.

**Can I stop system apps?**
Be careful when you stop apps. Only stop apps that you recognize. If you stop a critical system app, your computer might prompt you to restart. Bubo marks system apps clearly if you hover over them.
